BeeModel Zig: feature progress

Every feature of the x86-64 assembly BeeModel (v1.3, ~378k lines, 1240 operators) and where the Zig port stands. Source of the list: README.md, docs/UI.md, docs/*.md and the operator ids in src/*.s of the assembly repo. Updated with every step.

Order of work (the Ph column):
  1. Shell and UI core: operators, search, tooltips, undo, selection, transforms, themes, keyboard
  2. Editors and viewport UI: header, shading, pies, wheel, outliner, properties, colour picker, preferences, file browser
  3. Files: .bee, OBJ, STL, glTF, PNG, recent files, autosave
  4. Mesh editing and modelling tools
  5. Modifiers
  6. Materials, shading and rendering
  7. Animation and rigging
  8. Sculpt, paint, UV
  9. CAD and fabrication
  10. Physics and simulation
  11. Node editors and procedural
  12. AI, MCP, BeeScript
  13. Collaboration, world, platform
